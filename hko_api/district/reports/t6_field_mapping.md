# T6 字段映射 · 香港 18 区气象播报

> 生成：2026-10-27　页面：`hko_api/district/index.html`　规则：`hko_api/district/bulletin.js`
> 范围：仅使用 HKO 官方**观测/警告**接口；不接 nowcast 分区数值、不做实时模型推理。

---

## 1. 使用中的接口与字段

| 用途 | 端点 | 快照字段 | 实际字段 | 单位 | 空间口径 |
|---|---|---|---|---|---|
| 分区雨量 | `weather.php?dataType=rhrread` | `sources.rhrread.districts[]` | `place`、`max_mm`、`unit` | mm | **18 区**（官方区名） |
| 雨量统计窗口 | 同上 | `sources.rhrread` | `rainfall_start`、`rainfall_end` | ISO 时间 | 全港同一窗口 |
| 观测时刻 | 同上 | `sources.rhrread.obs_time` | ISO 时间 | — | 官方产品时刻 |
| 获取时刻 | 同上 | `sources.rhrread.fetch_time` | ISO 时间 | — | 本管道最后成功抓取 |
| 天气警告 | `weather.php?dataType=warnsum` | `sources.warnings.warnings{}` | `code`、`name`、`issueTime`、`expireTime`、`actionCode` | — | **全港级** |

页面实际读取的 18 个区名（HKO 原文，繁体）：中西區、東區、葵青、離島區、北區、西貢、沙田、南區、大埔、荃灣、屯門、灣仔、元朗、油尖旺、深水埗、九龍城、黃大仙、觀塘。

## 2. 明确不使用的数据（及原因）

| 数据 | 原因 |
|---|---|
| `nowcast`（网格临近预报） | 仅提供 ~2 km 网格产品，**无官方分区聚合**；按区自算会引入未经验证的空间降尺度，故本页不展示任何分区未来 2 小时数值 |
| `hourlyRainfall`（36 站） | 站点级，无「站点→18 区」官方归属；不作分区替代 |
| `hhot`（天文潮） | 与 18 区降雨播报无关，且为调和预报非实测 |
| `grid_500m_static.dc`（区编码） | 18 个编码（11–39）**无区名映射**，44 格缺失；不能把网格与官方区名关联 |
| `grid_scores`（历史模型评分） | 非实时；仅在 `../dashboard.html` 独立展示 |

## 3. 规则模板

雨量分级（`rainBand`）：

| 区间 | 级别文字 |
|---|---|
| `mm = 0` | 無錄得降雨 |
| `0 < mm < 1` | 微量降雨 |
| `1 ≤ mm < 5` | 小雨 |
| `5 ≤ mm < 15` | 中等降雨 |
| `15 ≤ mm < 30` | 大雨 |
| `mm ≥ 30` | 暴雨 |

播报结构（固定顺序，不插入任何推演内容）：

1. 过期警示（仅当快照过期/失败，`⚠` 开头）
2. 本区过去 1 小时最高雨量 + 分级 + 官方统计窗口
3. 全港生效警告（无则明确写"没有生效"），并标注**全港级、非本区专属**
4. 数据来源 + 官方观测时间 + 数据获取时间
5. 固定声明：不含未来降雨预测，也不代表水浸风险

异常分支：

| 状态 | 判定 | 页面行为 |
|---|---|---|
| 正常 | `ok=true`、`stale=false`、获取时间在阈值内 | 正常播报，徽标「官方觀測」 |
| 过期 | `stale=true` 或获取时间超 `max_age_min`（rhrread 30 min） | 顶部橙条 + 播报首段 `⚠` + 徽标「過期快照」；保留最后数值但强制标注 |
| 接口失败 | `ok=false` | 徽标「無數據」；正文说明接口未返回有效数据；**不显示任何数值** |
| 该区缺测 | 区列表存在但 `max_mm` 缺失 | 徽标「缺測」；明确不以邻区/全港平均代替；**不出现 mm 数值** |
| 整源无分区 | `districts` 为空 | 左栏「無分區數據」、播报「氣象數據暫不可用」 |

## 4. 与历史风险图层的关系

- 本页**不显示任何风险分数**；仅提供一个链接到 `../dashboard.html`（历史评分地图）。
- 原因：① 历史评分非实时；② 不存在可靠的「500 m 网格 → 18 区」官方映射（`dc` 无区名）；③ 混合展示会被误读为实时水浸概率。
- 历史风险图层本身仍完整保留在 Dashboard，未改动。
