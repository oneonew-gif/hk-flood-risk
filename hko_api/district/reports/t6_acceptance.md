## 4. 已知限制

| # | 限制 | 影响 |
|---|---|---|
| L1 | 无 18 区边界几何 | 只能做列表选择器，不能做分区面填色地图；不伪造边界 |
| L2 | 官方 nowcast 无分区产品 | 现阶段无法给出「分区未来 2 小时降雨」，故不展示 |
| L3 | `dc` 18 编码无区名映射、44 格缺失 | 无法把历史网格风险按官方区聚合；风险页与本页保持分离 |
| L4 | 分源轮询频率不同（rhrread 5 min、warnings 1 min） | 两卡片时间可能相差数分钟，已分别展示各自观测/获取时间 |
| L5 | 浏览器截图工具不可用 | 验收以 DOM 文本 + 控制台状态为准，无截图留档 |

- 未读取任何模型 bundle，未输出概率/风险数值。
