# 香港 18 區氣象播報（T6）

以香港天文台（HKO）官方開放數據為唯一數據源，按區展示**過去 1 小時降雨觀測**、**全港級警告**
與**規則化文字播報**。頁面不含任何未來降雨預報數值、不含水浸風險分數、不執行模型推理。

## 運行

```bash
# 1) 抓取官方數據（在倉庫根目錄；--loop 為常駐輪詢）
python3 hko_api/hko_fetch.py --once
# 或 python3 hko_api/hko_fetch.py --loop

# 2) 起本地靜態服務（必須從倉庫根目錄起，頁面引用 ../data/latest/）
python3 -m http.server 8000

# 3) 瀏覽
#    http://localhost:8000/hko_api/district/
```

`file://` 直接雙擊亦可運行（使用 `data/latest/snapshot.js` 打包快照），但不會自動刷新。

## 測試

node hko_api/district/tests/bulletin.test.mjs   # 規則模板 8 組：雨量邊界/缺測/失敗/過期/多警告/不含預報

## 數據口徑

| 顯示項 | 來源 | 說明 |
|---|---|---|
| 各區雨量 | `rhrread` → `districts[].max_mm` | 官方分區過去 1 小時最大雨量；區名原樣使用 |
| 統計窗口 | `rhrread` → `rainfall_start/end` | **全港統一**統計窗口，非分區各自窗口 |
| 警告 | `warnsum` | **全港級**資訊，不代表所選地區專屬 |
| 觀測時間 | `rhrread.obs_time` | 官方產品時刻 |
| 獲取時間 | 抓取管道寫入 | 用於判定快照是否過期 |

雨量分級（無錄得 / 微量 / 小 / 中 / 大 / 暴雨）為**本產品展示規則**，不是香港天文台官方分級。
分級只用於文字描述，不參與任何風險判斷。

## 異常處理

- 接口失敗：服務端保留上次成功快照並標 `stale`；頁面顯示「最後一次成功快照」警示條。
- 單區缺測：顯示「缺測」，不以鄰區或全港平均代替，也不推算數值。
- 快照過期：以**獲取時間**判定（`rhrread` 閾值 30 分鐘），官方觀測時間滯後屬正常。

## 已知限制

1. 無 18 區官方邊界幾何，故只有列表選擇器，不提供分區地圖。
2. HKO `nowcast` 為約 2 km 網格產品，無官方分區聚合，故不展示分區未來 2 小時數值。
3. 現有 500 m 網格風險評分無可靠的「網格 → 18 區」映射，故不把歷史風險分數按區聚合展示。
4. 本頁與歷史風險圖層嚴格分離：風險地圖見 `hko_api/dashboard.html`（歷史模型輸出，非實時）。

## 目錄

```
hko_api/district/
├── index.html          # 頁面
├── bulletin.js         # 純函數規則模板（可 node 單測）
├── tests/bulletin.test.mjs
└── reports/            # 字段映射、驗收記錄、發布檢查清單
```

數據目錄 `hko_api/data/raw/` 為時間戳歸檔（約 260 MB / 2,800+ 檔案），**不入庫**（見根目錄 `.gitignore`）。
`hko_api/data/latest/` 為當前快照與打包 JS 備用，供離線展示。

相關條款；本頁僅作官方觀測的規則化轉述，不構成任何預警或疏散指令。
