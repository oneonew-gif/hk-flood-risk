# Dashboard 数据说明

`latest/` 中保留的是一份供团队演示和前端开发使用的冻结快照：

- `snapshot.json` / `snapshot.js`：香港天文台公开气象资料的同一份快照，生成于 2026-10-27 17:02:34（Asia/Hong_Kong）；
- `grid_scores.json` / `grid_scores.js`：5,517 个网格的冻结历史模型评分，生成于 2026-10-26；
- `.json` 供本地 HTTP 服务读取，`.js` 供直接双击页面的 `file://` 备用模式读取。

这些文件不是实时服务，也不是水浸实测记录。页面必须展示观测时间和过期状态；模型评分只能解释为弱监督标签下的历史相对风险排序。

运行 `python3 hko_api/hko_fetch.py --once` 会更新本机气象快照。不要通过定时任务把每次抓取结果提交到 Git；确需替换团队演示快照时，应先核对数据来源、时间、字段变化和敏感信息，并由另一位同学复核差异。

`raw/` 及其他持续生成的数据仍由 `.gitignore` 排除。
