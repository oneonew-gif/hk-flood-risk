# 精选模型结果

本目录只保存适合团队协作和结果复核的小型冻结产物，不包含原始训练数据、逐行完整预测、模型 bundle 或全部实验记录。

## 文件

| 文件 | 用途 |
|---|---|
| `metrics.json` | 六类模型指标及空间稳定性等汇总数值 |
| `final_model_comparison.csv` | 六个模型在测试集上的核心指标对比 |
| `fig_roc_pr_test.png` | 测试集 ROC/PR 曲线 |
| `fig_shap_top20.png` | 主模型 SHAP Top 20 特征 |
| `fig_grid_risk_test_vs_full.png` | 测试期与全期网格评分对比图 |
| `fig_rain_tide_heatmap.png` | 雨量与潮位分层的描述性热力图 |

## 版本与口径

- 冻结时间：2026-10-26。
- 数据版本：`delivery_repaired_b1`。
- 训练/验证/测试按年份切分；测试期为 2023-01 至 2026-09。
- 正例来自暴雨警告归因窗口与易涝空间规则构成的弱监督标签，并非真实水浸记录。
- 模型输出是相对风险评分，不是校准后的水浸概率，也不证明已经具备提前两小时预警能力。
- 本目录文件选自本机冻结产物 `paper_package_b1_20261026-122643`；完整产物及其来源数据仍在仓库外管理。

核心结论不能只看 ROC-AUC：主 XGBoost 的测试集 ROC-AUC 约为 0.751、PR-AUC 约为 0.184；逻辑回归的 PR-AUC 约为 0.291。事件日内行级 ROC-AUC 约为 0.638，因此当前模型应被理解为探索性的历史空间风险排序。

## 更新规则

只有在数据版本、切分方式、标签定义和生成脚本都已确认时才替换这些文件。更新时应同步修改本说明，并在 Pull Request 中列出旧值、新值及变化原因。不要把整个 `outputs/` 强制加入 Git。
